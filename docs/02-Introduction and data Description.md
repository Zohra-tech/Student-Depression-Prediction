1. Introduction to the Dataset
In this project, I will be using a dataset called Student Depression Dataset that has information of 4,464 students of universities. There are 13 variables in the dataset related to demographic, academic, family, social, financial, and health aspects of the student.

This data set is used to analyze the correlation between the characteristics and the depression status of the university students. The aim is to see if these characteristics are able to predict the students suffering from depression by supervised machine learning classification techniques.

The data set has numerical and categorical variables. The numerical variables are age, current semester, CGPA, and cost without study, while categorical variables are gender, family background, relationship, marital status, living style, friends circle, health condition, and home division.

The variable for the target value is depression and whether the student is considered depressed (Yes) or not depressed (No). Since there are two categories in the target variable, this project is considered as a binary classification problem.
