# Student-Depression-Prediction
# Student Depression Prediction Using Machine Learning

## Overview
This project explores the application of machine learning techniques to identify patterns associated with depression among university students.

## Objectives
- Perform exploratory data analysis (EDA).
- Investigate relationships between student characteristics and depression.
- Develop classification models.
- Compare model performance.
- Interpret findings and discuss limitations.

## Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Git and GitHub
- Seaborn

## Project Structure
- `data/`: Dataset files (not necessarily included in the public repository).
- `notebooks/`: Jupyter Notebook analysis.
- `visualizations/`: Generated charts.
- `results/`: Model evaluation results.

## Machine Learning Models
Classification Model:
- Logistic Regression
- Decision Tree
- Random Forest
